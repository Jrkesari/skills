- Sign-in for capture: Playwright storage_state file capture/state.json holding the Better Auth cookie better-auth.session_token for domain localhost, plus capture/token.txt with the same value for curl checks. Stale better-auth.session_data.0/.1 cookie-cache cookies were stripped from state.json so only session_token remained. Health checks: curl -H "Cookie: better-auth.session_token=$T" http://localhost:3100/api/auth/get-session should return {session,user}, and /api/auth/token returns the Convex JWT that nexus server components use (lib/convex-server.ts fetchConvexToken -> authedConvexClient). Token and JWT values were always redacted in output (sed to '<redacted>'), never printed. | WHY: Lets capture scripts run headless as the real signed-in user without typing credentials, and tells an expired session apart from a broken API. | DO: Keep state.json with only the session_token cookie. Re-validate through get-session and /api/auth/token before filming. Never echo the token, and redact any JWT in printed output.
