# Edit and render (HyperFrames)

Scripts: `scripts/edit/` (engine.py, build.py, gen_media.py, prepare_media.py, style.css light, style_dark.css, timeline.json). `build.py` is the full 61 s launch film. Copy it and change the scenes for a new film.

## HyperFrames setup

```bash
export HYPERFRAMES_NO_TELEMETRY=1 HYPERFRAMES_FFMPEG_PATH=<film>/bin/ffmpeg.exe HYPERFRAMES_FFPROBE_PATH=<film>/bin/ffprobe.exe
npx -y skills@latest add heygen-com/hyperframes -a claude-code --copy -y --skill hyperframes --skill hyperframes-core --skill hyperframes-cli \
  --skill hyperframes-animation --skill hyperframes-creative --skill hyperframes-audio --skill hyperframes-keyframes --skill media-use --skill product-launch-video
npx -y hyperframes@0.8.134 init videos/<name>-<ratio> --non-interactive --example=blank --skill=product-launch-video
```

- **Always pin `hyperframes@0.8.134`.** A bare `npx hyperframes` installed 0.8.181 in the middle of the session and moved its snapshot output to `.hyperframes/artifacts/...`.
- After `init`, copy the vendored assets the skill ships: `scripts/shared/{gsap.min.js,grain.png,netigen-mark*.svg}` into `videos/<proj>/assets/lib/` and `scripts/shared/fonts/*.woff2` into `videos/<proj>/assets/fonts/`. Without them the timeline is blank and the fonts fall back. They are GSAP 3.14.2, a 512 px numpy noise texture, and the latin woff2 files from `@fontsource-variable/inter`, `@fontsource/instrument-serif` and `@fontsource/jetbrains-mono` 5.2.8.
- Theme: `build.py` reads `style.css` (light) by default and `style_dark.css` when `CAP_THEME=dark`.
- One HyperFrames project per aspect ratio, all generated by one `build.py <fmt>`.

## Architecture

- `timeline.json` is the **only** source of timing: duration, fps 30, vo_take, vo_timing, music, music_offset, `vo` (line start times), `vo_fix`, `scenes` (id, start, end) and `sfx`. Re-time it there, then rebuild the audio and the films.
- `engine.Film` writes one `index.html` with a paused GSAP timeline registered on `window.__timelines["main"]`, with `data-start`/`data-duration` clips and the audio element.
  - `window(x,y,w,h,t_in,t_out,enter='rise'|'zoom',exit_='fade'|'cut',tilt=(rotY,rotX))`: a framed white box. It enters 0.06 s early, and its exit overlaps the next scene's entrance so there is never an empty frame.
  - `plate(win, ww, wh, src, sw, sh, t0, t1, keys, video, xfade=0.28, dim, tag)`: a capture inside a window. Camera keys are `(t, cx, cy, zoom[, ease])` in the capture's CSS px. In `build.py`, `plate_s` takes an absolute scale instead of a zoom. A plate's last fade is skipped when the window's own exit hides it.
  - `words(...)`: a kinetic headline, each word rising out of a blur at its VO time. Set `lh` (line height) explicitly when serif words are scaled up, or the lines overlap.
  - `text(...)`: its exit never starts before the entrance has finished (`max(t_out-0.35, t_in+0.6)`). Without that, a tagline from one scene stayed on screen through the next two.
  - `captions(caps, ids, x, y, w, size, max_words)`: phrases from the word timings. Break at `.,:` once a phrase has 2 or more words, otherwise at max_words, and never leave one word on its own. Swap phrases with a hard set, never overlapping fades. Each word brightens as it is spoken. Captions run on the product lines only, not on the hook or end card.
- `gen_media.py` writes `media.json`: per format, the clips (`take`, `in`/`out` event specs, `dur` from the VO words) and the stills (`src`, `blur`, `patch`, optional `path` and `w` for website stills of 796 CSS px).
- `prepare_media.py <fmt> [names]` cuts the clips: speed = source span / target duration, `setpts`, lanczos scale, portrait `fillborders=right=10:mode=smear`, then each blur box as `split,crop,gblur=sigma=10:steps=3,overlay` (boxblur fails on small crops). Encodes libx264 crf 14. Stills come out as JPEG q93 with blur and patch baked in. Pass names to redo only those.
- `build.py <fmt>`: the story. Helpers include `t(line, word)` (the **first** occurrence of a word, since "it", "and" and "how" repeat), `clip_at(clip, event, start=None)` (the film time of a take event; the clip's film start defaults to the start of the scene named by its `scene` key in media.json), `plate_s`, `header`, `chip`, `card` and `product`.
- `gen_media.py` hard-codes the launch film's VO words (`t('l05','your')`, ...) and clip names. A new script means new word anchors and a new clip list. Keep the pattern, replace the values.
- **Value blurs, for live screens only** (the default is website scenes instead): `VAL = {still_name: [[x,y,w,h], ...]}` in gen_media.py, in capture CSS px. The launch film needed the Nimbus KPI tiles (about 210×48 at y=220 land), the cost KPI row (y=108) plus the y-axis labels and the total row, the agents KPI row plus a table row, the Naper seat count (about 110×30) and the overview stats strip. Guessed boxes missed (y=190 vs 108). Read them off a gridded still, then check a contact sheet of the processed stills. On real screens, blur the greeting name, KPI values, whole charts with their axes and labels (shapes and proportions leak), the org switcher and the user chip.

## Camera and framing rules (each one came from a confirmed defect)

- Frame the active area at a scale of 1.3 or more and push slowly (4-10% across a hold). A whole screen shrunk into a window is unreadable on a phone.
- Use one big window whose content swaps on the spoken word, not several small labelled cards. The small side cards for Naper seats and limits were unreadable and split attention.
- Website stills are 796×440 stage units (`WSZ`), so their camera scales run much higher (about 2.0-2.5 in a 16:9 window) than full-page stills. `build.py` branches on the `wsc_` prefix.
- Pick camera keys from a 100 px grid drawn over each still (with labels and a brighter line every 500 px). Never guess them.
- Give every push-in an explicit start and end scale, each chosen so no text is cut at either end. Keep a margin of 12 px or more and crop on column gaps or whitespace. Always crop at the sidebar divider (Nimbus: anchor x at the divider, 180 css px). Never show sidebar slivers.
- No line sliced horizontally at the window's top or bottom: exclude title strips by pushing the camera's cy below them. No composer or send button cut. No blank white column, and no empty lower 40% of a window.
- A dialog window should match the dialog's width, so the backdrop does not show as a second edge. Start on the short dialog, then pan when it expands (`clip_at(..., 'inherit-off')`).
- Time chips and callouts from take events (`clip_at`), not VO words. Put them over empty space, opaque from their first frame.
- Label any shot sped up more than about 3x as `TIME-LAPSE` (`.tag` at the bottom-right). Give each beat about 1 s or more on screen. Real speeds used: typing 4-5x, research about 16x, deck 76-213x, schedule 4-9x.
- When showing successive states of the same UI, use one continuous camera and dissolve between the states (xfade 0.25). Between layouts that look different, use a short xfade (0.15-0.18).
- When the match-cut camera keys of a clip and the still after it are identical, the dissolve does not ghost.
- Give every animated SVG part its own id (`mp0..mp2`): class-selector tweens get flagged as overlapping. Guard decorative pulses so they never overlap a later move. Ease colour pulses over about 0.6 s; hard toggles read as flicker.
- Scene descriptor text must exit before its scene ends (`start = min(ti+0.08, e1-0.95)`), or it bleeds into the next scene's first frame.
- Every decorative overlay (gradient, dim) gets its own in and out tweens.

## Check, snapshot, render

```bash
cd videos/<project>
npx -y hyperframes@0.8.134 check          # need 0 errors; warnings are advisory. lint --verbose names them.
rm -rf snapshots && npx -y hyperframes@0.8.134 snapshot --describe false --no-end --timeout 20000 --at 1.5,3.2,5.0,...   # about 30 moments; then read contact-sheet*.jpg (the default 5 s timeout is too short for 300+ tweens with video plates)
npx -y hyperframes@0.8.134 render --crf 14 --fps 30 --workers 2 --output renders/<project>-vN.mp4   # background; about 5 min per format for 61 s
```

- Check findings fixed during the session: content_overlap (line height, caption handoff), text_occluded (the caption band over the URL), duplicate_media_discovery_risk, overlapping_gsap_tweens, composition_file_too_large (advisory).
- `--video-frame-format png` is recommended for UI-heavy films.
- A render goes ahead despite lint errors unless you pass `--strict`. Overlapping tweens can also be fixed with `overwrite: "auto"`. A large composition can be split into `compositions/` files mounted with `data-composition-src`. To check when a chip appears, grep `tl.fromTo("#chipN"` in index.html.
- A 30-moment list for a 61 s film: 1.5, 3.2, 5.0, 6.8, 9.0, 12.0, 14.2, 16.5, 18.9, 20.6, 21.6, 23.0, 24.8, 27.0, 28.4, 30.2, 31.0, 32.4, 34.2, 36.2, 38.4, 40.6, 42.6, 44.6, 46.6, 48.8, 50.4, 51.8, 54.5, 58.0. After a fix, snapshot only the moments you touched.
- ffmpeg concat fails when the inputs mix 3840×2160 and 1920×1080. Normalise each first (`scale=1280:720,fps=30,setsar=1`). The drawtext "Fontconfig error" on Windows is harmless.

## Mux and finish

```bash
# landscape
ffmpeg -i render.mp4 -i audio/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -shortest -movflags +faststart deliver/<Name>-16x9.mp4
# portrait (HyperFrames 0.8.134 leaves a black 8 px strip at the right edge)
ffmpeg -i render.mp4 -i audio/mix.wav -map 0:v -map 1:a -vf "fillborders=right=8:mode=smear" -c:v libx264 -crf 14 -preset slow -pix_fmt yuv420p -c:a aac -b:a 256k -shortest -movflags +faststart deliver/<Name>-9x16.mp4
# preview under 30 MB to send
ffmpeg -i master.mp4 -c:v libx264 -crf 21 -preset slow -c:a copy -movflags +faststart deliver/preview/<Name>-<ratio>-preview.mp4
```

After every render, sample the last 10 pixel columns of a frame with PIL; a portrait snapshot will not show the strip a render has. Verify with ffprobe (duration, width, height) and with ebur128.

## Rebuild chain (from the first stage that changed)

```bash
cd <film>/audio && python -I build_audio.py --diag && bash norm.sh && cp mix.wav ../videos/<each project>/assets/mix.wav
cd <film>/edit && python -I gen_media.py <fmts...> && python -I prepare_media.py <fmt> [names] && python -I build.py <fmt>
```

Patch scripts with an exact-replace list that asserts each anchor occurs once (`assert s.count(a) == 1`). Write long patches to a file and run it: heredocs with nested quotes break in Git Bash. Open and write files with `encoding='utf-8', newline='\n'`. Use forward-slash paths in generated Python.
